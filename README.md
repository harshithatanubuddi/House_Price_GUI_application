# House Price Prediction Project

This project provides both Python and Java implementations for house price prediction.

## Structure

- `python_app/` : Python-based app using a trained machine learning model.
- `java_app/` : Java GUI app for house price prediction.
- `.gitignore` : Root-level gitignore to exclude general files like OS-specific or temporary files.

## How to Use

- For Python app, see `python_app/README.md`.
- For Java app, see `java_app/README.md`.

## Requirements

- Python 3.x
- Java JDK 8+
- Necessary libraries listed in `python_app/requirements.txt`
