# Python House Price Prediction 

This folder contains the Python application for house price prediction using machine learning.

## Contents

- `app.py` : Main Python application for UI or prediction.
- `Untitled.ipynb` : Jupyter notebook for training and exploring the machine learning model.
- `model/house_model.pkl` : Pre-trained machine learning model saved using pickle.
- `data/housing_dataset.csv` : Dataset used for training and testing the model.
- `requirements.txt` : List of Python dependencies needed to run the app.
